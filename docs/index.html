Keywords that
actually understand
your text.

TF-IDF counts words. semantic-keywords understands meaning. Uses sentence embeddings + Maximal Marginal Relevance to extract keywords that are relevant and diverse — fully offline, no API key required.

PyPI → GitHub
$ pip install semantic-keywords
why it's different

Built on real semantics.

Not word frequency. Not document position. Actual meaning — via 384-dimensional sentence embeddings.

embedding

Semantic understanding

Knows that "mobile money" and "fintech" are related, even if one never appears in the document.

mmr

MMR diversity

Maximal Marginal Relevance ensures you get 5 different keywords — not 5 paraphrases of the same idea.

offline

Fully offline

Download the model once (90MB). Then it runs forever with no internet, no API key, no rate limits.

flexible

Three model tiers

Pick fast, balanced, or accurate — the package detects what you've downloaded.

cli

Interactive CLI

Run semkw and get a guided prompt — or pipe text straight from the terminal.

api

Clean Python API

One function. Returns a ranked list of dicts. Drop it into any pipeline in two lines.

python api

Two lines to get started.

from semantic_keywords import extract

# Basic usage
results = extract("Tanzania is a hub for mobile money and fintech startups.")

for r in results:
    print(r["score"], r["keyword"])

# Full control
results = extract(
    text      = "your long paragraph here",
    top_n     = 10,
    min_score = 0.25,
    diversity = 0.7,
    model     = "balanced",
)

Returns a list of {"keyword": str, "score": float} dicts, sorted by relevance.

model tiers

Pick your power level.

The package auto-detects which models you've downloaded. No configuration needed.

Alias HuggingFace model Size Speed Note

accurate all-mpnet-base-v2 420 MB slower Best quality on CPU
